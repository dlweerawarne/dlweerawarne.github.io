# Personal academic website — October 2026

Static multipage HTML website for GitHub Pages.

## Install
1. Back up the existing `dlweerawarne.github.io` GitHub repository first.
2. Copy the supplied `index.html`, other `.html` files and `assets/` directory to the repository root.
3. Keep existing repository images, PDFs and LaTeX downloads: this package does not contain the originals.
4. Ensure GitHub Pages is serving the root of the correct branch and commit/push.
5. Visit each section after publication, especially publication links and downloaded resources.

## Editorial checks before publication
- Confirm exact institution/role wording and administrative titles.
- Check grant amounts and award years against certificates, especially the separately supplied 2025 awards.
- Publications is a selected bibliography, not a full continuously updated list.
- Add your own portrait and laboratory images only with permission; no image files are included.
- Review whether to publish phone number and CV PDF; neither is included.
- Copy legacy downloadable LaTeX template and any other assets from old repo before replacing anything.

All pages are real static HTML files. No build process, framework or JavaScript is needed. Styles are in `assets/style.css`; the font is requested from Google Fonts with fallback system fonts.
